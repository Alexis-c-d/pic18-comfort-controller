# PIC18 Environmental Comfort Controller

Comfort controller on a **PIC18F45K22** that reads light and temperature and drives actuators.

## Features
- LDR (light) and LM35 (temperature) sensing
- RS232 command interface
- PWM-controlled lamp
- LED indicators for fan and heater

## Toolchain
MPLAB X IDE · XC8 · Proteus (simulation)
